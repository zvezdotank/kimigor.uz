# kimigor.uz — личная страница Ким Игоря

Статическая визитка на трёх языках: RU (`/`), EN (`/en/`), UZ (`/uz/`).
Тёмная технологичная вёрстка: Golos Text на тексте, IBM Plex Mono на датах,
линии-волосинки вместо теней, один сигнальный синий `#6f9bff`.
Смысловой центр страницы — шкала должностей 2019–2026 и списки со ссылкой
на источник у каждой записи.

## Как править

Весь текст и ссылки лежат в одном файле — [`scripts/content.py`](scripts/content.py).
После правок:

```bash
python3 scripts/build.py
```

Скрипт перезаписывает `index.html`, `en/index.html`, `uz/index.html` и `sitemap.xml`.
Руками HTML-файлы не редактируем — следующая сборка затрёт правки.

Верстка — в [`site.css`](site.css). Если поменял CSS, подними `CSS_VERSION`
в [`scripts/build.py`](scripts/build.py:20), чтобы у посетителей не остался старый кэш.

## Правила контента

- **Каждый пункт — со ссылкой на источник.** Ссылка в поле `href`; если её нет,
  строка выводится без пометки «источник», а пустая секция не выводится совсем.
- **Секция «Отзывы» пока пустая** (`quotes: []` во всех трёх языках) — как только
  появятся реальные цитаты, добавляем их туда, и секция сама появится на странице.
- **Кейсы с цифрами временно сняты.** Кейс «+66% застройщику» убран по просьбе Игоря
  до того, как соберётся полный набор кейсов и его можно будет подать одним блоком.
- **Шкала должностей** живёт в `track` внутри каждого языка: `from` / `to` — годы,
  `key: True` подсвечивает полосу сигнальным цветом. Диапазон шкалы — `TRACK_YEARS`.
- **Facebook в контактах не выводится**, пока `FACEBOOK = ""` в `content.py`.
  Впиши туда ссылку на профиль — блок появится и в контактах, и в `sameAs` разметки.
- Числа и статусы в текстах — только те, что подтверждаются ссылками рядом.

## Календарь занятости

Раздел «Занятость» на `/contacts/` рисуется скриптом [`calendar.js`](calendar.js)
по данным из Google Календаря. Пока `CAL_URL` в `scripts/content.py` пустой,
раздела на сайте нет.

Как включить:

1. [script.google.com](https://script.google.com) → новый проект, вставить
   [`gcal/apps-script.gs`](gcal/apps-script.gs) целиком.
2. Развернуть → веб-приложение, запуск от своего имени, доступ «Все».
3. Полученный `https://script.google.com/macros/s/…/exec` вписать в `CAL_URL`
   и пересобрать сайт.

Наружу уходит только время «занято с … по …»: ни названий встреч, ни участников.
События «весь день», помеченные как «свободен» и отклонённые не учитываются.
Для проверки вёрстки без реального календаря есть [`gcal/sample.json`](gcal/sample.json) —
временно поставьте `CAL_URL = "/gcal/sample.json"`.

## Проверка вёрстки

Горизонтальная прокрутка — самая частая поломка: её даёт любой элемент шире
экрана, растяжка на `100vw`/`-50vw` или длинная строка без переносов. Проверять
нужно **все страницы на всех ширинах**, а не только главную на своём мониторе.

Вставьте [`scripts/check-overflow.js`](scripts/check-overflow.js) в консоль
браузера на открытом сайте: скрипт прогоняет девять страниц по десяти ширинам
от 360 до 1920 px и печатает виновников. Пусто — значит всё в порядке.

Что уже ловилось этим способом: фон плавающей шапки, растянутый на `-50vw`
(давал 562 px прокрутки на десктопе), и меню с телефоном, не помещавшиеся
в одну строку на 768 px.

## SEO

- У каждой страницы свой `canonical` и полный набор `hreflang` (ru/en/uz/x-default).
- Разметка `Person` (JSON-LD) с `sameAs` на Instagram, LinkedIn, страницу
  в правлении МАУ и профиль эксперта Kursiv.
- `robots.txt` и `sitemap.xml` — в корне.
